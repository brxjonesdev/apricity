#### Overview
Apricity is a writing tool for fiction writers that want to write stories with detailed characters, plots and worlds. The app allows users to plan, draft and share their stories all in one place.

#### Problem
Other great writing app such as Ulysses & Scrivener are great but they prioritize a broad organization that can apply to many authors writing any time of documents (fiction, non-fiction, essays, etc.). This makes it difficult for any author that wants more organization for any these categories. 

#### Target Users
Non-fiction authors that want not only a simple writing interface but also would like ways to organize plot points, characters and other details of their stories.

#### Goals
1. Allow users to write stories
2. Make it easier to plan and view plot lines
3. Make creating fleshed out characters simple
4. Provide a system for describing details about the world of the story
